 This repository contains all assignment notebooks, data analysis, and code developed for the Data Science & Generative AI module.
 [Assignment 1: Data and Feature Engineering](./Assignment_1/2_01_data_and_feature_engineering_in_pandas_COMPLETED.ipynb)


## Repository Overview

This repository contains a minimal demonstration of the structured machine
learning component discussed in the accompanying essay.

## Scope

The notebook focuses on producing classification outputs from structured
features under fixed assumptions. These outputs are intended to feed into
downstream optimisation processes, which are deliberately left out of scope.

## Purpose

The aim is to illustrate constrained model use rather than full automation,
reflecting the emphasis of the module on disciplined integration.
